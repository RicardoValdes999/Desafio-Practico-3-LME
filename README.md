# 🥖 Gourmet Delight Bakery - E-commerce Web Application

Proyecto web académico desarrollado como una tienda en línea (*e-commerce*) para una repostería artesanal, diseñado con una arquitectura de SPA (Single Page Application), estilizado con **Tailwind CSS** y estructurado bajo buenas prácticas de control de versiones y documentación.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5 / CSS3:** Estructura semántica y diseño visual base.
* **Tailwind CSS (CDN):** Framework utility-first para el diseño responsivo y moderno.
* **JavaScript (ES6+):** Lógica de componentes y interactividad SPA.
* **FontAwesome / Bootstrap Icons:** Iconografía institucional.
* **Git y GitHub:** Control de versiones
